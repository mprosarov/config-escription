#### Начало работы с проектом

1. Открыть терминал в любой папке и выполнить комманду:

```bat
browser-sync --version
```

2. Если терминал вернул версию, значит BS уже установлен,например:
   `2.26.14`
   преход к шагу 4.

3. Если не установлен то выполнить в терминале( в любой папке ):

```
npm install -g browser-sync
```

4. После этого в папке `\json-wizard` выполнить комманду в терминале

```bash
browser-sync start --server --files "**/*"
```

Запустится статический сервер, с отслеживанием изменений в файлах и авто перезагрузкой страницы, ссылка и порь будет выведена в консоль, по умолчанию:

```bash
 http://localhost:3000
```
